# Supported use cases
- Retrieve sales invoices from KSeF
- Retrieve purchase/expenses invoices from KSeF
- Cache accessed KSeF record on application storage layer
- Notification to submit invoices
- Automated execution of invoicing
- Automated compute and payment of taxes

# Features
- Modern TS codebase
- Cloudflare workers backend
- Secured behind Cloudflare ZeroTrust
- Friendly cloud SQL data-store
- Continuous integration
- Defensive application design
- No Ai auditory
- Workflow documentation
- 100% coverage E2E tests
- OpenAPI UI
- Live documentation
- Versioning and release process
